---

## Reporting a Vulnerability

If you discover a security vulnerability or exploit (such as crash exploits, arbitrary code execution, or server duplication issues) within **Create Shared**, please do **NOT** open a public issue.

Instead, report it responsibly via:
1. **GitHub Private Vulnerability Reporting**: Use the "Report a vulnerability" button under the **Security** tab of the repository.
2. If private reporting is unavailable, reach out directly to the repository maintainer.

### What to include:
- A description of the vulnerability and its potential impact.
- Steps or a minimal test scenario to reproduce the issue.
- Any suggested fixes or mitigations.

We will acknowledge receipt within 48 hours and work with you to test and release a security patch promptly.
