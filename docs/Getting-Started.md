# Getting Started

Welcome to **Create Shared**! This page covers everything you need to download, install, and run the mod.

---

## 📋 Requirements

Before launching the game with Create Shared, make sure you have the following installed:

1. **Minecraft**: `1.21.1`
2. **Mod Loader**: [NeoForge](https://neoforged.net/) (`21.1.262` or newer)
3. **Java**: OpenJDK 21 or higher
4. **Mandatory Dependency**:
   - [Create Mod](https://curseforge.com/minecraft/mc-mods/create) (`6.0.0+` for 1.21.1 NeoForge)
5. **Recommended Companions**:
   - [JEI (Just Enough Items)](https://curseforge.com/minecraft/mc-mods/jei) for recipe viewing and crafting lookups.

---

## 📥 Installation

### For Players (Client)
1. Download the latest version of **Create Shared** from GitHub Releases, Modrinth, or CurseForge.
2. Download the required version of **Create** for Minecraft 1.21.1 NeoForge.
3. Place both `.jar` files into your Minecraft instance's `.minecraft/mods` folder.
4. Launch the game using your NeoForge 1.21.1 launcher profile.

### For Server Administrators
1. Set up a NeoForge 1.21.1 server.
2. Place `create_shared-[version].jar` and `create-[version].jar` into the server's `mods/` directory.
3. Start the server. Configuration files will be generated under `config/create_shared/`.
