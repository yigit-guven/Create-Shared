# Welcome to the Create Shared Wiki!

**Create Shared** is a modern Minecraft mod designed for **NeoForge 1.21.1**, integrating seamlessly with the **Create** mod and offering deep compatibility with **Just Enough Items (JEI)** and related community addons.
