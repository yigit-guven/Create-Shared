# Compatibility Guide

**Create Shared** is engineered to maintain high compatibility across the Minecraft and Create modding ecosystem.

---

## ⚙️ Create Mod
- **Status**: Required (Mandatory)
- **Features**:
  - Full support for Create contraptions, stress networks, shafts, cogwheels, Encased Fans, belts, and gearboxes.
  - Integration with Create's player tooltips, Engineer's Goggles, and information displays.
  - Ponder scenes integrated for items and blocks.

---

## 🔍 Just Enough Items (JEI)
- **Status**: Optional / Fully Supported
- **Features**:
  - Displays all custom recipes and processing steps.
  - Click-through recipe lookups for crafting, stonecutting, and smithing recipes.

---

## 🛠️ Other Addons & Tech Mods
- **Dependent Create Addons**: Automatically integrates their configurations into Create: Shared's unified in-game configuration menu.
- **Curios API / Accessories**: Works alongside standard cosmetic and accessory inventories.
- **Storage Mods** (Sophisticated Backpacks, Applied Energistics 2, Refined Storage): Standard item transfer interfaces are compatible with Create's item transports.
- **Performance Mods** (Embeddium / Sodium, FerriteCore, ModernFix): Fully compatible.
