# Compatibility Guide

**Create Shared** is engineered to maintain high compatibility across the Minecraft and NeoForge modding ecosystem.

---

## ⚙️ Create Mod
- **Status**: Required (Mandatory)
- **Supported Versions**: `6.0.0+` on NeoForge 1.21.1
- **Features**:
  - Full support for Create contraptions, stress networks, shafts, cogwheels, belts, and gearboxes.
  - Integration with Create's player tooltips, goggles, and information displays.
  - Ponder scenes integrated for items and blocks.

---

## 🔍 Just Enough Items (JEI)
- **Status**: Optional / Fully Supported
- **Supported Versions**: `19.0.0+` on NeoForge 1.21.1
- **Features**:
  - Displays all custom recipes and processing steps.
  - Click-through recipe lookups for kinetic machine crafting.
  - Anvil, crafting table, and mechanical press recipe integration.

---

## 🛠️ Other Addons & Tech Mods
- **Curios API / Accessories**: Works alongside standard cosmetic and accessory inventories.
- **Storage Mods** (Sophisticated Backpacks, Applied Energistics 2, Refined Storage): Standard item transfer interfaces are compatible with Create's item transports.
- **Performance Mods** (Embeddium / Sodium, FerriteCore, ModernFix): Fully compatible. Ensure Flywheel backend is set to default (instanced or batching) for best graphics card compatibility.
