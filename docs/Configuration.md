# Configuration

**Create Shared** provides configuration files allowing you to tweak balance, server behavior, and client visual settings.

---

## 📂 Configuration Files

All configuration files are generated in your `.minecraft/config/` (or server `config/`) directory upon initial startup:

- `create_shared-common.toml`: Shared gameplay, mechanics, and kinetics parameters.
- `create_shared-client.toml`: Client-side visual preferences, tooltips, and rendering options.
- `create_shared-server.toml`: World-specific rules, saved per world save in `saves/<world>/serverconfig/`.

---

## 🔧 Common Options

### Kinetics & Stress
- **`stressCapacityModifier`**: Multiplier applied to stress capacity generated by shared kinetic components (Default: `1.0`).
- **`stressImpactModifier`**: Multiplier applied to stress impact consumed by shared machines (Default: `1.0`).

### Multiplayer & Sharing
- **`enableTeamSharing`**: Whether kinetic networks and shared components can be linked across team members (Default: `true`).
- **`maxSharedConnections`**: Maximum allowed shared connections per block (Default: `16`).
