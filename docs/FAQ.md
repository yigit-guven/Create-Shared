# Frequently Asked Questions (FAQ)

### Q: Does this mod require the Create mod?
**A:** Yes! Create Shared is an addon built specifically for the Create mod on NeoForge 1.21.1. Create must be installed in order to run.

---

### Q: Which version of JEI should I use?
**A:** Any stable JEI release for Minecraft 1.21.1 NeoForge (version 19.x or newer).

---

### Q: Can I use this mod in my modpack?
**A:** Yes, absolutely! You are free to include Create Shared in public or private modpacks as long as you respect the LGPL-3.0 license.

---

### Q: I found a bug or my game crashed. Where do I report it?
**A:** Please open an issue on our [GitHub Issue Tracker](https://github.com/YigitGuven/Create-Shared/issues) using the Bug Report or Crash Report templates. Make sure to attach your `debug.log` or crash report using [mclo.gs](https://mclo.gs/) or Pastebin.

---

### Q: Will there be backports to older Minecraft versions (e.g. 1.20.1)?
**A:** Our primary development target is Minecraft 1.21.1 on NeoForge. Backports to older versions are not currently planned.
