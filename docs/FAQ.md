# Frequently Asked Questions (FAQ)

### Q: Does this mod require the Create mod?
**A:** Yes! Create Shared is a library and content addon built specifically for the Create mod. Create must be installed in order to run.

---

### Q: Which version of JEI should I use?
**A:** Any stable JEI release matching your Minecraft version and mod loader.

---

### Q: Can I use this mod in my modpack or as a dependency for my own Create addon?
**A:** Yes, absolutely! You are free to include Create Shared in public or private modpacks and depend on it in your own Create addons. See the [Developer & Library Guide](https://github.com/YigitGuven/Create-Shared/blob/main/DEVELOPER_GUIDE.md) for instructions on integrating with Create Shared's unified configuration system and APIs.

---

### Q: I found a bug or my game crashed. Where do I report it?
**A:** Please open an issue on our [GitHub Issue Tracker](https://github.com/YigitGuven/Create-Shared/issues) using the Bug Report or Crash Report templates. Make sure to attach your `debug.log` or crash report using [mclo.gs](https://mclo.gs/) or Pastebin.
