**Create Shared** is an addon mod for Minecraft **1.21.1** on **NeoForge**, built to expand the cooperative capabilities of the **[Create](https://curseforge.com/minecraft/mc-mods/create)** mod. It introduces collaborative mechanics, shared kinetic contraptions, and seamless multiplayer integration while maintaining full recipe lookup compatibility with **[Just Enough Items (JEI)](https://curseforge.com/minecraft/mc-mods/jei)**.

---

## 🚀 Features

- **Mandatory Create Integration**: Deeply integrates with Create's rotational power network, stress capacity, speed controllers, and contraptions.
- **Multiplayer Cooperation**: Share rotational power, contraptions, and logistics with team members.
- **Ponder Scenes**: Visual in-game animated tutorials powered by Create's Ponder system.
- **JEI Recipe Support**: Inspect recipes, kinetic processing steps, and crafting recipes right in JEI.

## 📥 Installation

1. Install **[NeoForge](https://neoforged.net/)** for Minecraft `1.21.1`.
2. Download the latest version of **[Create](https://curseforge.com/minecraft/mc-mods/create)** for 1.21.1 NeoForge.
3. Download **Create Shared** from [Releases](https://github.com/YigitGuven/Create-Shared/releases).
4. *(Optional)* Download **[JEI](https://curseforge.com/minecraft/mc-mods/jei)** for 1.21.1 NeoForge.
5. Place all downloaded `.jar` files in your `.minecraft/mods` directory.
6. Launch Minecraft using your NeoForge profile!

## 🛠️ Development & Building

To clone and compile the project locally:

```bash
git clone https://github.com/YigitGuven/Create-Shared.git
cd Create-Shared
./gradlew build
```

To run the development client in your IDE:
```bash
./gradlew runClient
```
